# AVer web application

Django application for document upload, cloze tests and authorship scoring.
The NLP service that selects blanks is provided separately in [`../WebAPI`](../WebAPI/).

## Run locally

Requires Python 3.12+, [uv](https://docs.astral.sh/uv/), Docker Compose (or an
existing Redis service), and GNU gettext (`msgfmt`) for translations.
Run these commands from `WebApp/`:

```sh
uv sync --locked --no-dev
cp .env.example .env
uv run --no-dev python -c 'import secrets; print(secrets.token_urlsafe(50))'
```

Set `SECRET_KEY` in `.env` to the generated value. Django and Celery load this
file automatically; existing environment variables take precedence.
Set `MUNI_API_BASE` to your NLP service URL if you host it yourself. The default
uses the MUNI service and sends uploaded document text there for analysis.
Access to a compatible running service is required for AI analysis.

```sh
docker compose up -d redis
uv run --no-dev python manage.py compilemessages
uv run --no-dev python manage.py migrate
uv run --no-dev python manage.py loaddata languages academic_fields
uv run --no-dev python manage.py createsuperuser
uv run --no-dev python manage.py fetch_pos_models
uv run --no-dev python manage.py runserver
```

In another terminal, also from `WebApp/`:

```sh
uv run --no-dev celery -A aver worker -l INFO
```

Open <http://127.0.0.1:8000/>. Register an account and upload a document.
The database starts empty apart from language and academic-field reference data;
no demonstration documents, accounts or study responses are distributed here.
The data page describes the research dataset but does not provide a bundled download.

## Downloads and generated files

`uv.lock` records the dependency versions. Stanza POS models (approximately
700 MB) are downloaded by `fetch_pos_models`. The sentence-transformer scoring
model downloads on first use and is cached by Hugging Face. These downloads
require network access and additional disk space; model files are not source files
and are not committed. Translation `.mo` files are generated by `compilemessages`.

## Deployment

The included Compose file is only a local Redis service. For deployment, supply
Redis URLs and a fresh `SECRET_KEY` through environment variables or a private
`.env`, set `DEBUG=False`, and configure `ALLOWED_HOSTS`,
`CSRF_TRUSTED_ORIGINS`, and `CORS_ALLOWED_ORIGINS` for your HTTPS origin.
Run migrations, load the reference fixtures, compile translations and run
`uv run --no-dev python manage.py collectstatic --noinput` before starting:

```sh
uv run --no-dev gunicorn --bind 127.0.0.1:8000 aver.wsgi
uv run --no-dev celery -A aver worker -l INFO
```

Use an HTTPS reverse proxy that supplies `X-Forwarded-Proto` and serves
`static-collected/` at `/static/`. Keep `db/` and `media/` persistent and private.
Do not expose uploaded documents as public static files. Back up both directories.
Keep environment files out of source control, build contexts and logs.

## Calibration

The scoring constants and their derivation are documented in
[`docs/calibration.md`](docs/calibration.md) (Czech).
`scripts/audit_calibration.py` reproduces the unigram counts from a separately
supplied study CSV; that private dataset is not included.
